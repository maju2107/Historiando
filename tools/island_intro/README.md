# Island opening and Kai

The existing wake-up and island tour lead into Kai's entrance, a Portuguese Pleistocene/PlayStation exchange, and the return-home mission. The later epoch popup was removed from the route trigger because Kai explains it in the conversation. The mission target is derived from the island's collectible container (currently 31), and its side-panel section persists beside changing parkour objectives.

`dialogo/linha_do_tempo/kai_encontro.dtl` contains the dialogue and performance cues. `island_intro.gd` controls the cameras, movement lock, effects and clean skip/handoff. `assets/characters/FacialAnimator.gd` blends speech mouth shapes, listener reactions and blinks. Mouth timing is text-driven; no recorded voice or audio lip-sync is supplied.

Both opening timelines are native editable `DialogicTimeline` resources, exposed as **Waking Dialogue** and **Kai Dialogue** in Opening's **Diálogos / Dialogic** Inspector section. See `dialogo/README.md` for editing them in Dialogic's timeline editor. `validate_dialogue_input.gd` saves and reloads a disposable edited timeline using Dialogic's own resource format, displays it with the existing banner, and verifies the source speech is unchanged. A/Y use 46-pixel badges, overlapping their lower-right corners, with 4× SVG rasterization (528 pixels) and mipmaps for clean scaling. Mobile still hides the controller signs.

## All-fragment ending

`Ending` in `CenarioIlha.tscn` subscribes to the HUD's once-only `fragments_completed` signal. The final real pickup queues the cutscene outside the physics callback. It locks movement, clears touch state, stops the platform controller and saves phase one through the existing `FaseCore` API. A paper-colored dissolve moves the actors off any disappearing platform into the authored open clearing; terrain rays ground Kai. The original opening, character meshes and rigs are retained.

`dialogo/linha_do_tempo/ilha_final.dtl` is a native editable Dialogic timeline with eight speeches, a new souvenir/giant-ground-sloth joke, expressions and camera cues. It uses the same manual speech banner, corner A prompt and mobile screen-tap behavior. The finale includes a branded spiral portal with orbiting fragment shapes, a goodbye walk, and an input-safe completion menu with Replay and Return Home. The menu displays the actual goal, preserves saved phase progress and cannot accidentally resume the completed scene via Y/Esc. Pause/skip are also available during the ending. Reduced motion disables the portal swirl and orbit and shortens camera transitions.

`validate_ending.gd` exercises 30/31 versus 31/31 real pickups, once-only triggering, grounded actors and unobstructed portal framing, both speakers' faces, camera/portal pause, actual save persistence, reduced motion, replay, return-home navigation and early/speech skips. It restores the user's progress file and in-memory flags afterward. `capture_ending.gd` renders GPU previews under `previews/ending`, using `ending_preview` so captures never write progress. Existing intro/collectible tests explicitly disable the finale to keep their own checks isolated; the ending test covers the complete handoff. Neither the game nor its dialogues advance automatically; timed inputs exist only in the review helper.

The final pickup now has a roughly seven-second handoff before dialogue: a gentle landing/idle blend and camera settle, 1.6 seconds with the completed mission counter visible, a HUD fade and completion burst, then a 1.15-second paper dissolve and 1.35-second clearing reveal with a short pause before speech. The platforms freeze immediately so the celebratory hold is safe. The normal-speed GPU capture includes `pickup_hold`, `fragments_gather` and `return_to_clearing`.

The shared comic burst wraps words and fits its font into the solid center, rather than using the outer spikes as text bounds. Ending bursts have more room, a longer reading hold, and screen margins for their rays. `validate_effects.gd` checks every opening/ending phrase, actual Label bounds against the burst polygon, word preservation, font metrics and resizing; running it without `--headless` also saves `previews/ending/effect_text_fit.png`.
