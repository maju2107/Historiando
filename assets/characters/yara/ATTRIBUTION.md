Yara character geometry and design: user project assets.

Animations adapted from Gobot by GDQuest, CC-BY 4.0: https://github.com/gdquest-demos/godot-4-3D-Characters/tree/8034d3fede52c8a58d2cbc7b8d3e8e6c79f6c8b3
